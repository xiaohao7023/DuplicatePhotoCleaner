## 崩溃修复（21:40-22:10）
- 症状：V1.4 新版一开就闪退（实际是任一分类扫描完成、Dashboard tile 渲染 `"\(count) items · \(size)"` 时崩），重启→重扫→再崩，看起来像"Screenshot 反复扫描"。
- 根因：`Localizable.xcstrings` 中 key `%lld items · %@` 的 en/de/es/fr/pt-BR/ja 译文被写成拍扁复数串（`one: %lld item · %@\nother: …`），4 个格式符只传 2 参 → `%@` 读垃圾指针 → EXC_BAD_ACCESS objc_opt_respondsToSelector(0x30c)。崩溃签名与 .ips 完全吻合。V1.4 新 tile 用 `·`（旧版用 `•`）才踩中。
- 修复：① catalog 6 条脏译文拍平；② 源码 5 处"插值后紧跟 %"改为 String(format:)（SimilarGroupsView % similar、PaywallDeleteSheet Storage warning、OnboardingView ×2、FreeTierCard）——这些 key 无翻译语言会回退 key 当格式串，`% s` 必崩。
- 验证：修复版真机跑了 4 分钟+（覆盖原崩溃时间线）无新崩溃日志。
- 教训：AI 生成多语言翻译时禁止把复数规则拍平进 stringUnit；LocalizedStringKey 里含 % 必须用 String(format:)。
